# 💥 Destroy Simulator (Roblox)

Режим-«симулятор»: ломай блоки, получай монеты, качай силу, делай ребёрты.
Всё строится кодом: арену, блоки и интерфейс создают сами скрипты, руками рисовать ничего не нужно.

## Что есть в игре

- **5 видов блоков**: Ящик → Камень → Сейф → ✨ Золотой → 💎 Алмазный (о нём узнаёт весь сервер)
- **Удары кликом** (на телефоне — тапом), всплывающий урон, **криты x3**
- **Комбо**: чем быстрее бьёшь, тем больше монет (до x2)
- **Магазин силы**: «+1» и «Купить макс»
- **Ребёрты**: сбрасывают силу и монеты, но навсегда дают +50% монет
- **🔥 Золотая лихорадка** каждые 3 минуты: монеты x2, мир становится золотым, падает дождь из золотых блоков
- Награда за блок делится между всеми, кто его бил (можно ломать боссов толпой)
- **Сохранение прогресса** и таблица лидеров в списке игроков

## Как запустить (пошагово)

### 1. Установи Roblox Studio
Зайди на <https://create.roblox.com>, нажми **Start Creating** и установи Studio. Войди в свой аккаунт Roblox.

### 2. Создай место
В Studio нажми **New** → шаблон **Baseplate**.

### 3. Открой нужные окна
Сверху вкладка **View** → включи **Explorer** и **Properties**.
Explorer — это дерево всех объектов игры, оно появится справа.

### 4. Вставь серверный скрипт
1. В Explorer наведи на **ServerScriptService** → нажми **⊕** → выбери **Script**.
2. Переименуй его в `GameServer` (F2).
3. Двойной клик → удали `print("Hello world!")` и вставь всё содержимое файла **`GameServer.server.lua`**.

### 5. Вставь скрипт интерфейса
1. В Explorer раскрой **StarterPlayer** → наведи на **StarterPlayerScripts** → **⊕** → **LocalScript**.
2. Переименуй в `GameClient`.
3. Вставь содержимое файла **`GameClient.client.lua`**.

> ⚠️ Важно: первый — именно **Script**, второй — именно **LocalScript**. Если перепутать, работать не будет.

### 6. Нажми ▶ Play
Появится арена с блоками. Кликай по блокам, копи монеты, жми кнопки слева.

## Сохранение прогресса

В Studio без настройки прогресс не сохраняется (в Output будет жёлтое предупреждение — это нормально).
Чтобы включить:

1. **File → Publish to Roblox** — опубликуй место (придумай название).
2. **Home → Game Settings → Security** → включи **Enable Studio Access to API Services** → **Save**.

## Как открыть игру друзьям

1. **File → Publish to Roblox**.
2. **Game Settings → Permissions** → **Public** → **Save**.
3. Игра появится у тебя в профиле на roblox.com, ссылку можно кидать друзьям.

## Как настроить под себя

Всё в начале файла `GameServer.server.lua`:

| Что поменять | Где |
|---|---|
| Сколько блоков на карте | `CONFIG.MaxBlocks` |
| Как часто лихорадка | `CONFIG.EventEvery` (в секундах) |
| Шанс крита | `CONFIG.CritChance` |
| Бонус за ребёрт | `CONFIG.RebirthBonus` |
| HP, награда, цвет, редкость блоков | таблица `BLOCK_TYPES` |
| Цена улучшений | функции `upgradeCost` и `rebirthCost` |

Можно добавить свой блок: скопируй любой `{ ... }` в `BLOCK_TYPES` и поменяй значения.

> Если меняешь `ComboWindow` на сервере, поменяй и `COMBO_WINDOW` в `GameClient.client.lua`.

## Если что-то не работает

Открой **View → Output**: туда пишутся ошибки красным. Скопируй текст ошибки и пришли его.
