# 💥 Destroy Simulator (Roblox)

Симулятор в блочном стиле: ломай блоки-руды киркой, качай кирку, собирай питомцев, открывай новые миры и меняйся с друзьями.
Всё строится кодом: карту, блоки, кирки, питомцев и интерфейс создают сами скрипты.

## Что есть в игре

- **3 блочных мира** с холмами, деревьями, лавой и облаками:
  - 🌿 **Луга**: трава, земля, брёвна, камень, уголь, железо, золото, 💎 алмазы
  - 🔥 **Нижний мир** (💰 50K): адский камень, песок душ, кварц, светокамень, адское золото, древние обломки
  - 🌌 **Край** (💰 5M): камень Края, обсидиан, пурпур, кристаллы, яйцо дракона
- **Порталы** у спавна каждого мира и меню 🌍 Миры
- **7 кирок**: деревянная, каменная, железная, золотая, алмазная, незеритовая и кирка Края. Кирка в руках, удар кликом.
- **Уровни кирки** (кнопка слева): урон растёт с каждым уровнем
- **5 аддонов для кирок**: ⚡ Эффективность (урон), 🍀 Удача (монеты), 🎯 Меткость (криты),
  💥 Взрыв (бьёт блоки вокруг), 🤖 Автокопка (кирка бьёт сама). Чем круче кирка, тем выше можно прокачать аддоны.
- **13 питомцев** в 3 яйцах: курица, свинка, овечка, волк, аксолотль, магмовый куб, страйдер, ифрит, гаст,
  эндермит, шалкер, эндермен и мифический 🐉 Дракон Края. Питомцы ходят за тобой и дают бонус к монетам.
  Можно надеть 3.
- **Трейды**: обмен питомцами между игроками (оба жмут «Готов», потом идёт отсчёт 3 сек)
- Криты, комбо, ребёрты, 🔥 Золотая лихорадка каждые 3 минуты, сохранение прогресса

## Как запустить (пошагово)

1. Roblox Studio → **New** → шаблон **Baseplate**.
2. **ServerScriptService** → **⊕** → **Script**. Удали всё внутри и вставь **`GameServer.server.lua`**.
3. **StarterPlayer** → раскрой стрелочкой → **StarterPlayerScripts** → **⊕** → **LocalScript**.
   Удали всё внутри и вставь **`GameClient.client.lua`**.
4. Нажми **F5** (Play).

> ⚠️ LocalScript должен лежать **внутри StarterPlayerScripts**. Если он лежит прямо в StarterPlayer
> или где-то ещё, кнопок и меню не будет.

Должно получиться так:
```
ServerScriptService
   └ Script
StarterPlayer
   └ StarterPlayerScripts
        └ LocalScript
```

Если обновляешь старую версию, не создавай новые скрипты: открой существующие, удали всё внутри (Ctrl+A, Delete) и вставь новый код.

## Сохранение прогресса

1. **File → Publish to Roblox**.
2. **Home → Game Settings → Security** → включи **Enable Studio Access to API Services** → **Save**.

Без этого в Studio будет жёлтое предупреждение в Output, это нормально.

## Как открыть игру друзьям

**File → Publish to Roblox**, затем **Game Settings → Permissions → Public**.
Не пиши «Minecraft» в названии и описании игры: Roblox может её за это заблокировать.

## Как настроить под себя

Всё в начале `GameServer.server.lua`:

| Что поменять | Где |
|---|---|
| Кирки: урон, цена, цвет | `PICKAXES` |
| Аддоны: цена и рост цены | `ADDONS` |
| Питомцы: бонус, редкость, внешний вид | `PETS` |
| Миры, блоки, яйца и шансы | `WORLDS` |
| Сколько блоков, лихорадка, криты | `CONFIG` |

## Если что-то не работает

Открой **View → Output**. Туда красным пишутся ошибки. Скопируй текст ошибки и пришли его.
