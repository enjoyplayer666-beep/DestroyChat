Команды LuckPerms для персонала (вводить в консоль сервера, без / в начале,
или в игре с / в начале). Префикс группы - иконка в табе, ник белый (&f),
суффикс - зелёная галочка. Чат DestroyChat берёт оформление персонала из
config.yml -> group-formats, поэтому иконка в чат не попадёт.

ВАЖНО: вместо <ИКОНКА> вставь символ-иконку из своего ресурс-пака
(у curator, moderator и media иконки при отправке сообщения потерялись).
Если группа уже есть, creategroup просто скажет, что она существует - это нормально.

--- admin ---
lp creategroup admin
lp group admin meta removeprefix 1000
lp group admin meta setprefix 1000 "🤪 &f"
lp group admin meta removesuffix 1000
lp group admin meta setsuffix 1000 " &a&l✔"

--- curator ---
lp creategroup curator
lp group curator meta removeprefix 1000
lp group curator meta setprefix 1000 "<ИКОНКА> &f"
lp group curator meta removesuffix 1000
lp group curator meta setsuffix 1000 " &a&l✔"

--- manager ---

--- выдать группу игроку ---

lp user <ник> parent add admin        (добавит группу к имеющимся)

=====================================================================
 ПРАВА КОМАНДЫ ПРОЕКТА (вводить в консоль, по одной строке)
=====================================================================
Группы не наследуют друг друга: у каждой свой набор прав, чтобы в чате
и /stat показывалась именно её привилегия. Вес (weight) - кто "старше".

--- вес групп ---
lp group curator setweight 900
lp group admin setweight 800
lp group manager setweight 700
lp group moderator setweight 600
lp group media setweight 500
lp group mediajr setweight 400

--- всем 6 группам: чат-префикс, стили, цвета, /color, /nickcolor ---
(повтори для curator, admin, manager, moderator, media, mediajr - замени имя группы)
lp group mediajr permission set destroylobby.prefix.chat true
lp group mediajr permission set destroylobby.prefix.format true
lp group mediajr permission set destroylobby.chat.colors true
lp group mediajr permission set destroylobby.chat.color true
lp group mediajr permission set destroychat.nickcolor true

--- moderator, manager, admin: видеть локальный чат на любом расстоянии ---
lp group moderator permission set destroylobby.chat.spy true
lp group manager permission set destroylobby.chat.spy true
lp group admin permission set destroylobby.chat.spy true

--- manager и admin: управление кланами, статистикой, бустерами, /destroychat reload ---
lp group manager permission set destroychat.clan.admin true
lp group manager permission set stat.booster.give true
lp group admin permission set destroychat.admin true
lp group admin permission set destroychat.clan.admin true
lp group admin permission set stat.admin true
lp group admin permission set stat.booster.give true
lp group admin permission set stat.booster.15 true

--- curator: почти OP - все права, кроме выдачи OP и выключения сервера ---
lp group curator permission set * true
lp group curator permission set minecraft.command.op false
lp group curator permission set minecraft.command.deop false
lp group curator permission set minecraft.command.stop false
lp group curator permission set bukkit.command.restart false

Если какие-то права у команды проекта не работают - проверь, что у игрока именно эта группа:
lp user <ник> info
